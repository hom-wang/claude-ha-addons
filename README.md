# claude-ha add-ons

Home Assistant add-on repository.

| Add-on | What it does |
|---|---|
| [HA Report Hub](ha-report-hub/) | Serves a folder of generated report pages (`/config/ha-report-hub/`) behind Home Assistant login via Ingress. Read-only, no exposed ports. |

Add this repository in Settings → Add-ons → Add-on store → ⋮ → Repositories: `https://github.com/hom-wang/claude-ha-addons`
